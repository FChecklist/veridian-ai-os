TASK 1 — ChatGPT Audit Workspace

OBJECTIVE
Build a secure VERIDIAN ChatGPT Audit Workspace.

PURPOSE
This workspace exists only for ChatGPT to perform deep software audits of VERIDIAN AI OS.
ChatGPT must NEVER modify production source code.
ChatGPT only produces audit reports.

CREATE
/SERVER/ChatGPT_Audit/

ChatGPT has READ:
Entire VERIDIAN Repository, Entire Metadata, Entire Documentation, Entire Database Schema,
Entire Workflow Definitions, Entire Business Rules, Entire APIs, Entire UI Metadata,
Entire Reports, Entire Prompt Library, Entire Capability Registry, Entire Route Registry,
Entire Audit History, Entire Logs.

WRITE allowed ONLY inside /SERVER/ChatGPT_Audit/

Inside create: Architecture/ Business/ Capabilities/ Modules/ Metadata/ Database/ Rules/
Workflow/ APIs/ UI/ Reports/ Security/ Performance/ AI/ Prompts/ Routes/ Testing/
Dependencies/ Integrations/ Observability/ Release/ Recommendations/ History/

Every audit generated by ChatGPT must contain: Audit ID, Timestamp, Repository Version,
Commit Hash, Files Analysed, Modules Analysed, Standards Used, Missing Items, Duplicate Items,
Incomplete Items, Risk Score, Priority, Recommendation, Implementation Suggestion, Confidence %.

Every audit must be versioned. Never overwrite previous audits. All audits must be searchable.
Generate audit indexes automatically. Maintain a master audit catalogue.
Every audit must be linked to: Capability, Workflow, Metadata, Business Rule, Database, API, UI,
Report, Document.
Never modify production files. Only create reports. Log every action.

Success Criteria: ChatGPT can audit the complete VERIDIAN repository without changing production
code. All audit reports are stored only inside /SERVER/ChatGPT_Audit/. Everything is version
controlled.

TASK 2 — ChatGPT Prompt Library Workspace

OBJECTIVE
Build a VERIDIAN Prompt Library Workspace.

PURPOSE
ChatGPT will continuously build and maintain the complete Prompt Library for VERIDIAN AI OS.
This Prompt Library becomes the master language dataset for the entire platform.

CREATE
/SERVER/ChatGPT_Prompt_Library/

ChatGPT has READ: Entire Repository, Entire Metadata, Entire Capability Registry, Entire Module
Registry, Entire Entity Registry, Entire Database Schema, Entire Workflow Registry, Entire
Business Rules, Entire APIs, Entire UI Metadata, Entire Reports, Entire Documents, Entire
Notifications, Entire Automation Registry, Entire Route Registry, Entire Variables, Entire Audit
Reports.

WRITE allowed ONLY inside /SERVER/ChatGPT_Prompt_Library/

Create folders: CSV/ Intent/ Keywords/ Variables/ Capabilities/ Entities/ Modules/ Domains/
Routes/ Coverage/ Validation/ Duplicates/ Statistics/ Reports/ History/

Generate 100 CSV files. Each CSV contains exactly 100 prompts. Total 10,000 prompts.

Every prompt must contain: Prompt ID, Prompt, Intent, Business Domain, Module, Capability,
Business Process, Entity, Action, Variables, Keywords, Expected Software Capability, Expected
Output, AI Required (Yes/No), Confidence.

Rules: Never use example company names. Never use real people. Always use typed placeholders,
e.g. <Customer.Name> <Project.Name> <Invoice.Number> <Employee.Name> <Vendor.Name>
<Document.Name> <Date> <Amount>.

Prompt generation must be based ONLY on actual capabilities found in the repository. Never invent
software that does not exist. If capability is missing, create a recommendation instead.

Every prompt must map to: Capability, Workflow, Business Rules, Metadata, API, Route.

Automatically detect: Duplicate prompts, Duplicate intents, Missing capabilities, Missing prompt
coverage, Missing variables, Missing workflows.

Maintain: Prompt Coverage %, Capability Coverage %, Intent Coverage %, Duplicate %.

Never overwrite previous prompt libraries. Version everything. Automatically regenerate affected
prompts whenever software changes.

Success Criteria: The Prompt Library always reflects the current VERIDIAN software. All prompts
are traceable to actual capabilities. Everything is version controlled. Everything is searchable.
