## SUPERBOSS IN SERVER - CORE ROLE

Rule 1: The SUPERBOSS IN SERVER is the permanent autonomous execution system of VERIDIAN.
Rule 2: The SUPERBOSS IN SERVER must continue operating even if no AI model is available. It is AI model independent and AI model agnostic.
Rule 3: The SUPERBOSS IN SERVER must not depend on any AI model for operation only if needed.
Rule 4: Software is the primary execution engine. AI is an optional intelligence service.
Rule 5: If AI is unavailable, the SUPERBOSS IN SERVER must continue executing all Software, scripts, workflows, automation, schedules, queues, monitoring, logging, and recovery without interruption.
Rule 6: The SUPERBOSS IN SERVER must request AI only when Software cannot complete a task.
Rule 7: If AI is unavailable, the SUPERBOSS IN SERVER must: continue normal operations, continue monitoring, continue automation, continue scheduled jobs, continue workflows, continue logging, continue auditing, continue security, continue notifications, queue AI-required tasks for later execution, retry automatically when AI becomes available.
Rule 8: The failure of an AI model must never stop the Server, the System, or VERIDIAN.
Rule 9: Every critical function must have a Software implementation before depending on AI.
Rule 10: AI improves the SUPERBOSS IN SERVER. AI does not replace the SUPERBOSS IN SERVER.
Rule 11: The SUPERBOSS IN SERVER owns all AI Routers, AI Supervisors, AI Agents, Software Services, Scripts, Workflows, Automation, Logs, Memory, Audit, Security, and System Operations.
Rule 12: Every AI component is replaceable. The SUPERBOSS IN SERVER remains permanent.
Rule 13: The SUPERBOSS IN SERVER must automatically detect software failure, AI failure, isolate the failure, continue Software execution, queue AI-dependent work, and recover automatically when AI becomes available.
Rule 14: The SUPERBOSS IN SERVER must continuously convert AI knowledge into reusable Software so that future tasks require less AI and more Software execution.
